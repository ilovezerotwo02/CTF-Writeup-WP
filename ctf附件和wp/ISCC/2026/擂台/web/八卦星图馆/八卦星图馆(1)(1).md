# 八卦星图馆 WP

## 题目思路

这题一共四步，对应 `乾 -> 兑 -> 离 -> 震`。

## 1. 乾卦：MongoDB 注入登录

登录点是 `POST /qian/login`，前端虽然是表单，但实际提交的是 JSON。

用户名必须是 `qingyun`，密码字段做 NoSQL 注入即可：

```json
{
  "username": "qingyun",
  "password": {
    "$regex": ".*"
  }
}
```

成功后可以拿到 session，进入后续卦象页面。

## 2. 兑卦：越权修改用户字段

`/dui/update` 没有做字段白名单，存在典型的 mass assignment。

可以直接提交额外字段，把自己的角色改成长老：

```json
{
  "role": "elder"
}
```

这样就能进入下一关抢令牌。

## 3. 离卦：并发抢头香令牌

`POST /li/grab` 存在竞态条件，题面也提示了它的逻辑是“先读、判断、延迟、再写”。

因此使用同一个 session 并发发送多个请求，就可以在“每人限 1 张”的限制下抢到多张令牌。拿到 3 张即可进入下一关。

实现方式随意，Python 线程、Burp Parallel 或并发脚本都可以。

## 4. 震卦：预测随机数并最终提权

`/zhen/history` 会返回历史签号，页面提示签号由 `Math.random()` 生成。

利用历史输出可以恢复其内部状态，进而预测当前轮次的正确签号。提交格式如下：

```json
{
  "round": "当前期号",
  "number": "预测值",
  "tokens": [
    "token1",
    "token2",
    "token3"
  ]
}
```

第一次提交即使预测正确，也会提示“掌门方可入”，说明还需要再利用 `/dui/update` 改角色。

这里把角色改成 `admin` 即可通过：

```json
{
  "role": "admin"
}
```

然后带着正确预测值和 3 张令牌重新提交，得到 flag。
