## 程序概览

该程序模拟一个"定时炸弹"，需要依次通过三关密码验证才能拆除。每关通过后增加10秒计时，超时则"爆炸"。

### 保护机制（不阻碍静态分析）

- `v4j8()`: `IsDebuggerPresent()` 反调试
- `d6b8()`: 通过 `GetTickCount` + `Sleep(100)` 检测时间异常
- `nn5s4()`: 对计时器 `seconds` 字段的一致性校验（tick_guard）
- `j8j7()`: 静态返回 `true`，仅在调试打断点时检测

以上所有保护均不影响静态逆向，只需保证最终的三个密码正确即可。

## Stage 1: 8字符密码 + 魔方加密

### 加密流程

密码为8个可打印ASCII字符（0x21–0x7E），经过以下变换后校验哈希：

1. **PKCS#7 填充**至16字节（8字节密码 + 8字节 `0x08`）
2. **2×2×2 魔方加密**，密钥为 `"R U F R' D2"`，展开为6步：`R → U → F → R' → D → D`
3. **Base64 编码**
4. **FNV1a-32 哈希**

校验条件：`FNV1a(Base64(Encrypt(password))) ^ 0xA5A5A5A5 == 0x8D93FFF8`

即 `FNV1a(Base64(Encrypt(password))) == 0x28365A5D`

### 魔方加密原理

每个魔方步对8字节块做**置换 + 加法（mod 256）**：

```
block → add(block[i] += move.add[i]) → permute(out[move.perm[i]] = block[i])
```

通过手动追踪6步的复合效果，得到**整体仿射变换**：

| old pos | new pos | add值 |
|---------|---------|-------|
| 0       | 5       | +8    |
| 1       | 1       | +14   |
| 2       | 0       | +23   |
| 3       | 3       | +8    |
| 4       | 6       | +5    |
| 5       | 7       | +11   |
| 6       | 4       | +23   |
| 7       | 2       | +4    |

解密即为反向操作：先逆置换再减去add值。

### 获取正确密码

```cpp

```

验证：加密 `ZVYHMYFA` → Base64 → FNV1a → `0x28365A5D` ✓

## Stage 2: 线性方程组

### 参数生成

Stage 1 的 FNV1a 哈希值 `H = 0x28365A5D` 用于生成 Stage 2 的参数：

**系数向量 g_a：**
```
base_a = [2, 3, 4, 5, 6]
g_a[i] = base_a[i] + ((H >> (i*6)) & 0x3)
```
得到 `g_a = [3, 4, 5, 6, 6]`

**方程右端 g_e：**  
通过 LCG 生成5个随机数 `x[0..4]`，代入方程组得到：
```
x = [2, 35, 72, 95, 14]
g_e = [55, 214, 490, 656, 181]
```

### 方程组

```
 3*x1 +   x2 +            x5 =  55
  x1 +  4*x2 +   x3         = 214
         x2 +  5*x3 +   x4  = 490
                x3 +  6*x4 + x5 = 656
  x1 +                 x4 + 6*x5 = 181
```

用高斯消元（分数精确运算）求解得：
```
x = [2, 35, 72, 95, 14]
```

格式化密码：`x1`（1位） + `x2`（2位） + `x3`（2位） + `x4`（2位） + `x5`（2位）  
得到 **`235729514`**

## Stage 3: 迷宫路径

### 迷宫生成

种子计算：
```
seed = atoi("235729514") ^ (0x28365A5D * 0x9E3779B1)
     = 0x40499D27
```

迷宫生成算法：
- 从 `(0,0)` 出发，只向右/向下，用 LCG 随机决定方向
