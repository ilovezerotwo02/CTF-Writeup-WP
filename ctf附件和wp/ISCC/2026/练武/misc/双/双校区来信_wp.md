## 题目概述

- **类型**：Misc 综合（图片隐写 + 音频频谱 + 拼图重组）
    
- **考点**：文件末尾附加数据提取、音频频谱分析、拼音编码拼接、信息关联推理
    
- **附件**：`shnu.jpg`、`campus_broadcast.wav`
    
- **提示**：“别只看图，广播更重要；找到顺序，口令自然会出现。”
    

---

## 解题过程

### 1. 图片隐写数据提取

题目提示“广播更重要”，暗示音频将给出关键信息，但“别只看图”也意味着图片中另有玄机。

使用工具检查 `shnu.jpg`：

- 直接 `binwalk -e shnu.jpg` 或 `foremost` 分离文件。
    
- 用十六进制编辑器观察，在 JPEG 结束标志 `FF D9` 之后，存在 RAR 压缩包的文件头 `52 61 72 21`。
    
- 手动截取或工具提取，得到一个受密码保护的 `hidden.rar`。
    

### 2. 音频频谱获取密码

打开 `campus_broadcast.wav`，根据“广播更重要”的提示，重点分析音频内容。

- 将音频导入 Audacity，切换至**频谱图（Spectrogram）**视图。
    
- 在频谱上可以清晰看到按时间先后出现的字母：**h、d、b、x、q、s、d、x**。
    
- 连起来即字符串 `hdbxqsdx`，这八个字母正好对应提示中的“顺序”和“口令”。
    

### 3. 解压 RAR 并分析碎片

使用密码 `hdbxqsdx` 解压 `hidden.rar`，得到若干文本文件，文件名分别为：

text

xue, xing, shi, qiu, hou, du, de, bo

每个文件内包含一小段看似随机的字符串，依次是 pL0k、8qQ、4fD、J2hG、wE3r、6sA、T5yU、7iO9 等。

### 4. 排列顺序的推理

题目强调“找到顺序，口令自然会出现”。音频给出的字母 `hdbxqsdx` 不仅是密码，还暗示了碎片拼接顺序。观察文件名均为拼音，结合常见高校校训，可联想到“**厚德博学，求是笃行**”（北京理工大学校训），其拼音首字母组合正是 `h d b x q s d x`，且顺序与音频频谱中的字母完全一致。

由此确定文件的排列次序为：

1. **hou** (厚) → h
    
2. **de** (德) → d
    
3. **bo** (博) → b
    
4. **xue** (学) → x
    
5. **qiu** (求) → q
    
6. **shi** (是) → s
    
7. **du** (笃) → d
    
8. **xing** (行) → x
    

### 5. 拼接内容获取 Flag

按上述顺序逐一读取文件内容并拼接：

- hou：`wE3r`
    
- de：`T5yU`
    
- bo：`7iO9`
    
- xue：`pL0k`
    
- qiu：`J2hG`
    
- shi：`4fD`
    
- du：`6sA`
    
- xing：`8qQ`
    

拼接得到：`wE3rT5yU7iO9pL0kJ2hG4fD6sA8qQ`

按照题目要求，包裹上 `ISCC{}` 即得最终 flag。
