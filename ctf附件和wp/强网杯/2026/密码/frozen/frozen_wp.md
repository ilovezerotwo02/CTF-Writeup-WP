## 1. 题目在干什么

服务端用 Falcon 风格的方式生成密钥：

- `N=128, q=12289, sigma=19.16`；
- `f, g` 为高斯小系数多项式，`F, G` 由 NTRU 塔式求解 + Babai 约化得到；
- 公钥 `h = g/f mod (x^N+1, q)`；
- 真正用于加密的是

```
D = f·adj(f) + g·adj(g)          # 128 个整数
fk = SHA256("frozen:" + ",".join(str(D_i)))
ct = flag XOR SHA256-CTR(fk)
```

所以只要能恢复 D，就能解密。

D 与内存泄漏的关系：`D` 的 negacyclic FFT 恰好是

```
G00_j = |f(ρ_j)|^2 + |g(ρ_j)|^2 ,  ρ_j = exp(iπ(2j+1)/N)
```

而 `G00` 正是 Falcon 签名树（Gram 矩阵的左上块）的根。题目把扩展密钥：

```
[ fh 实部/虚部, gh 实部/虚部, Fh 实部/虚部, Gh 实部/虚部,  Falcon 树节点, 树叶子 ]
```

共 **3328 个 double** 序列化后做“冷启动衰减”：

- 每个 double 的第 0..55 位与第 63 位（符号位）按位翻转；
- 原来是 1 的位以 `rho10=0.01` 翻成 0，原来是 0 的位以 `rho01=0.001` 翻成 1；
- 然后**删除前 1024 个 double**（正好是 `fh, gh, Fh, Gh` 的实虚部），只下发剩余 **2304 个 double**。

因此我们拿不到 FFT 原像，只剩下 Falcon 树。要做的就是：**从被位翻转污染的树里恢复 G00，再做逆 FFT 得到 D**。

一次实测（开发实例）的污染强度：树里 1024 个 double 中约 143 个相对误差 >1e-6，61 个 >10%；整包指数位变化 63 次、符号位翻转 16 次、尾数位变化 549 次。朴素重建完全失败，必须做结构化纠错。

## 2. 内存布局（这一步最容易错）

`expanded_doubles()` 的写入顺序不是“深度优先交错”，而是：

```
vals = [ fh.real(128), fh.imag(128), gh..., Fh..., Gh... ]     # 前 1024 个，被删掉
     + [ Ltop 的 real(128) + imag(128) ]                       # 256 个
     + [ T(G00) 全部节点，先序 ]                                # 896 个 double（448 个复数）
     + [ T(Dright) 全部节点，先序 ]                              # 896 个 double
     + [ T(G00) 全部叶子 ]                                      # 128 个
     + [ T(Dright) 全部叶子 ]                                   # 128 个
```

合计 `256+896+896+128+128 = 2304`。

**坑**：两棵树的节点全部集中在前面，叶子全部在最后；按“节点-左子树-右子树”交错解析会错位（症状：左链叶子解出 ~1e-18，重建全 0）。

树节点长度序列（先序）：`64,32,16,8,4,2,1,1, 2,1,1, ...`，每个节点存 `[real..., imag...]`。

## 3. 树里的数学结构（纠错依据）

记某个节点对应的 E 数组长度为 n，其节点 L 长度为 h=n/2。可以验证：

1. **所有 E 都是实正数组**；节点值满足
   ```
   L_j = D_j · ρ_j ,  ρ_j = exp(iπ(2j+1)/(2h)) ,  D_j ∈ R
   ```
   注意相位分母是 `2h`（父层根），不是 `h`——写成 `exp(iπ(2j+1)/h)` 会整体错。

2. **反对称性**：`D_{h-1-j} = -D_j`。这让我们把“每个分量的 2 个观测（实部、虚部）”扩展成 4 个（再借用镜像分量），大幅提高纠错能力。

3. **子节点关系**（E 的两半为 x=E[:h], y=E[h:]）：
   ```
   Ee     = (x+y)/2                       # 左子 = 算术平均
   D      = (x-y)/(x+y)
   右子   = 2xy/(x+y) = Ee·(1-D²)         # 调和平均
   ```
   右子树完全由左子 + D 决定，是冗余校验。

4. **G00 对称**：`G00_j = G00_{127-j}`，所以未知数只有 64 个。

5. **最深层 n=2 的节点 D 恒为 0**（由对称性 E_0=E_1）。但原始代码里 `cos θ_j ≈ 6e-17`，相消误差会把 L 的实部放大成 1e-2 量级“假值”。这一层必须直接令 `D=0`，否则会引入大块 1e-2 误差（这是本次踩的最大坑）。

## 4. 恢复算法

整体分三步：自底向上的“共识重建” → 对数域退火 Gauss-Newton → 严格一致集精修。

### 4.1 共识重建（解出绝大多数错误）

自底向上重建：`E_parent = [Ee(1+D), Ee(1-D)]`。关键是如何从被污染的 L 里挑出正确的 D：

对每个分量 j（h>1）：

- 直接观测候选（4 个，彼此独立）：
  ```
  |re_j|/|cosθ_j|, |im_j|/|sinθ_j|, |re_p|/|cosθ_p|, |im_p|/|sinθ_p|,  p=h-1-j
  ```
  其中 p 的观测对应 -D_j（反对称）。
- 比值候选：`sqrt(1-E2/E1)`（j 与 p 各一个）。
- **幅度**：在对数域用 **1e-9 相对精度聚类**，取最大簇。干净的观测彼此一致到 1e-15；被指数位污染的值会差 2^k，被尾数污染的差 1e-3~1e-1，都会被 1e-9 的紧阈值排除。优先用直接观测的簇，簇长≥2 即可得到高精度幅度；只有在直接簇不存在时才用比值簇/中位数兜底。
- **符号**：4 个直接观测做贝叶斯加权多数票。符号位 0→1 翻转概率 0.001，1→0 翻转概率 0.01，所以“存储值为正”的票更可信。
- n=2（h=1）直接令 D=0。

这一步在 20 个随机实例上，16 个直接 128/128 全对；其余误差也压到 1e-4~1e-2。

### 4.2 对数域退火 Gauss-Newton

把 G00 的对数当未知量 `u ∈ R^64`（对称展开成 128）。预测函数按树关系在 log2 域递推：

```
Ee = max(x,y) + log2(1+2^{min-max}) - 1
D  = tanh((x-y)ln2/2)
log|D|、log|child2| 同理
```

污染模型：`观测值 log2 = 真值 log2 + 整数 k + 小噪声`（指数位翻转 ⇒ 整数偏移，尾数位翻转 ⇒ 小噪声）。因此每轮把残差 `r = o - pred(u)` 的整数部分 `k = round(r)` 扣掉（只接受 `|r-k|<0.2` 的），再对 `r-k` 用 Cauchy 权重做加权 Levenberg–Marquardt/Gauss-Newton，权重尺度从 3e-2 逐级退火到 1e-4，并做线搜索。

同时屏蔽无效观测：预测 `|D|` 极小（log2 预测 < -25）的分量其实是浮点噪声，不能当约束（否则会被“整数取整”误当成有效约束，把拟合带偏）。

### 4.3 严格一致集精修

退火 GN 后误差约 1e-5～1e-6，但仍被“轻度污染的尾数观测”系统性偏置。最后按调度

```
3e-3, 1e-3, 3e-4, 1e-4, 3e-5, 1e-5, 3e-6, 1e-6, 3e-7, 1e-7,
3e-8, 1e-8, 3e-9, 1e-9, 1e-10
```

只保留 `|r - round(r)| < 阈值` 的“几乎完全一致”观测，做线性最小二乘（冻结整数偏移），每级迭代 3 次。真干净的观测残差只有 1e-12 量级，会逐级被保留；被污染的会被剔除，从而把 u 压到 1e-11 量级。

### 4.4 逆 FFT 与解密

逆变换公式（negacyclic）：

```
D_k = (1/N) Σ_j G00_j · ρ_j^{-k}
```

矩阵形式要**转置**：`(G00 @ M.T.conj())/N`（写成 `G00 @ M.conj()` 是错的，`ρ_j^{-k} ≠ ρ_k^{-j}`，这个坑会让人怀疑人生）。取实部后四舍五入得整数 D，再用题面的 `SHA256("frozen:"+","join(D))` 做 keystream 解密。

实测两个实例的整性误差 `max|D_real - round(D_real)|` 分别为 `3.7e-8` 和 `4.8e-8`，明文均为：

```
flag{25dcf4d6-a232-4c07-bc83-c4c760dd499c}
```

## 6. 踩坑速查

| 现象 | 原因 |
|---|---|
| 左链叶子解出 -1.5e-18，G00 全是 0 | 内存布局按“节点/叶子交错”解析；实际是两棵树节点在前、叶子在后 |
| 逆变换后 D 与预期差 1e5 | 逆 FFT 矩阵没转置：应为 `M.T.conj()` |
| 重建整体差 2 倍/常数 | 节点相位写成 `exp(iπ(2j+1)/h)`；正确是 `exp(iπ(2j+1)/(2h))` |
| 总有 ±1e-2 的块误差 | n=2 节点由对称性 D=0，但 cosθ≈0 把浮点噪声放大；必须置 0 |
| GN 卡在 1e-3~1e-5 不再下降 | 轻度尾数污染观测系统性偏置；需逐级收紧阈值只保留严格一致集 |
| 拟合把“预测 D≈0”的噪声观测当成整数偏移约束 | log 截断导致残差 ~几百，恰好落在整数上；要加 `pred > -25` 掩码 |
