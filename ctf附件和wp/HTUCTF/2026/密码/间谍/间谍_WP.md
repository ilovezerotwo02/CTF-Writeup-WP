# 间谍 — Writeup

**题目类别：** Crypto（摩斯电码）  
**附件：** `间谍`（63 字节纯文本，动态生成，每队不同）  
**Flag：** `HTU-MORSE-0ZQK`  
**提交格式：** `XXX-XXXXX-XXXX`，被拒时试 `XXX-XXXXX-XXXX.txt`

## 题目内容

```
1111 0 110 011110 00 000 101 111 1 011110 00000 0011 0010 010
```

题面"你是间谍吗"＋ 0/1 + 空格，第一时间就能锁定**摩斯电码**：`1`/`0` 当点划，空格当字母分隔。

## 关键：方向别搞反

摩斯只有两种映射，必须都试：

| 映射 | 结果 | 判断 |
|---|---|---|
| **1 = 点（·）、0 = 划（−）** | `HTU-MORSE-0ZQK` | 全是合法码组，有含义 |
| 0 = 点、1 = 划 | `[----]EG[.----.]ISKOT[.----.]5[..--]FR` | 出现 4/5 位的不存在码组，且无意义 |

反向映射里 `0011`→`..--`、`00000`→`.....` 等根本不是摩斯码组，直接排除。

## 逐段对照

| 0/1 | 摩斯 | 字符 |
|---|---|---|
| `1111` | `....` | H |
| `0` | `-` | T |
| `110` | `..-` | U |
| `011110` | `-....-` | **-**（连字符本身也是编码出来的） |
| `00` | `--` | M |
| `000` | `---` | O |
| `101` | `.-.` | R |
| `111` | `...` | S |
| `1` | `.` | E |
| `011110` | `-....-` | **-** |
| `00000` | `-----` | 0 |
| `0011` | `--..` | Z |
| `0010` | `--.-` | Q |
| `010` | `-.-` | K |

## 两个容易踩的点

1. **连字符是数据，不是分隔符**：`-....-` 是摩斯里的连字符码组，三条 `-` 全靠解码得到，恰好把明文切成题目要求的 `XXX-XXXXX-XXXX`。如果手写脚本时把 `-` 当分隔符过滤掉，就凑不出格式。
2. **末段是动态码**：`0ZQK` 四位随机（动态附件，每队不同），和官方示例 `AAA-ILOVE-HNSF` 的结构一致——前三位固定 `HTU`，中段是提示词 `MORSE`，末段才是你的那串。

## 复现

```bash
python solve_spy_morse.py
# 1=点 True  -> HTU-MORSE-0ZQK   OK
# 1=点 False -> [----]EG[.----.]ISKOT[.----.]5[..--]FR   (含无法识别的码组)
```

脚本：`solve_spy_morse.py`（含正反两种映射对照，也支持传入自己的 0/1 串）。
