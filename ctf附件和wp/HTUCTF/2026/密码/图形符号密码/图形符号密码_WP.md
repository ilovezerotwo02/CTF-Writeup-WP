# 图形 / 符号密码 — Writeup

**题目类别：** Crypto（图形密码）  
**附件：** 题目描述幻灯片截图（一句中文 + 9 个手绘风符号，第 7、8 个相同）  
**Flag：** `HTUCTF{HTU_IS_COOL}`

## 题目分析

题面是幻灯片：

> Crypto 很枯燥，其实不然。密码充满了乐趣：

后面跟着 9 个手绘风格的符号，**没有任何字母/数字提示，也没有对照表**。这类"图形密码"在 CTF 里通常是有固定套路的，常见候选有：

| 图形密码 | 特征 |
|---|---|
| 猪圈密码 Pigpen | 符号由网格线段构成，棱角分明 |
| 骑士密码 / 圣殿骑士 | 十字形骨架 + 点位置 |
| 共济会密码 | 类似猪圈，带横竖格 |
| **外星人密码 Alien Language** | 圆润手绘小人造型，和本题观感一致 |
| 跳舞的小人 | 火柴人姿态编码 |

## 确定编码体系

对照《CTF 密码学中的一些常用图形密码》（cnblogs.com/mumuhhh/articles/17774458.html）里列的 25 种图形密码，本题用的是其中 **第 12 种「外星人密码」（Alien Language）**，dCode 上有同名解码器。

## 自动化识别（不靠肉眼）

因为手绘符号和标准表有出入，直接肉眼比对容易错，所以用**模板匹配**做客观判定：

1. 把博客里那张 A–Z 对照表图按 26 个格子切开，得到 26 个标准模板；
2. 把题目截图里的 9 个符号同样切格、归一化尺寸；
3. 逐个模板算归一化互相关（NCC），取最高分。

结果每个符号的最高分都在 **0.80 ~ 0.87**，而第二名普遍 ≤ 0.48，结果唯一：

```
H  T  U  I  S  C  O  O  L
```

其中第 7、8 个符号确实是同一个字母 **O**，和题面观察一致——这也反证了识别没错（若是误判，两个不同字母被识别成同一字符的概率很低）。

## 明文与 Flag

明文就是 `HTU IS COOL`，包上 flag 格式：

```
HTUCTF{HTU_IS_COOL}
```

## 复现

```bash
python match.py     # 模板匹配，输出每个符号的 top 候选与得分
python verify.py    # 生成 verify.png，逐字符可视化核对
```

`verify.png` 是逐字符核对图：左为题目符号，右为命中的模板及得分。

## 踩坑记录

- 一开始想按猪圈密码硬套，但本题符号是**圆润曲线**造型，和猪圈的折线段落差明显，NCC 得分也上不去（<0.6），据此排除。
- 手绘符号有粗细抖动，直接像素级比对不可行；必须先**二值化 + 归一化到同一尺寸**再做相关，否则平移几个像素分数就崩。
