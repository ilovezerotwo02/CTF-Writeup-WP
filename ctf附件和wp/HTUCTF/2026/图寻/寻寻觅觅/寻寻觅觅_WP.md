# 寻寻觅觅 — Writeup

**题目类别：** OSINT / Misc  
**题目名称：** 寻寻觅觅  
**附件：** `寻寻觅觅.zip`  
**Flag 格式：** `HTUCTF{md5}`

## 题目描述

> 众里寻他千百度，蓦然回首，那人正在灯火阑珊处。
>
> 找到风景图片所在城市，例如：故宫的所在城市是北京。
>
> 再按照顺序排列：`风景1_风景2_风景3_风景4_风景5`，最后转为 MD5。

## 解题思路

这是一道图片地理定位题。附件解压后共有五张照片，题目要求的是**城市名**，不需要写具体景点、省份或区县。先依次识别每张图片的位置，再用下划线拼接五个城市名，最后计算整个字符串的 MD5。

这里最需要注意的是顺序和格式：图片必须按照 `风景1` 到 `风景5` 排列；`张家界市` 等地名需要按题目例子处理成 `张家界`；城市之间是半角下划线 `_`，不包含空格。

## 解题过程

### 风景 1：张家界

![风景1](images/风景1.jpg)

第一张图是仿古建筑内的游玩场景，前景手持的是游戏道具券。观察券面边框的小字，可以看到“七十二奇楼”等相关字样，与图片里的沉浸式街区相对应。通过检索“七十二奇楼”确认景区位于**湖南省张家界市永定区**。

因此，第一张图片对应的城市为：`张家界`。

参考：[湖南省人民政府——七十二奇楼，越夜越精彩](https://www.hunan.gov.cn/hnszf/hnyw/szdt/202405/t20240505_33292041.html)

![风景2](images/风景2.jpg)

第二张图是一处岩石上的“虫二”刻字。这里的“虫二”并不是普通的文字组合，而是“風月”二字去掉外围边框后的写法，有“风月无边”的含义。检索相关石刻可定位到**泰山**。泰山景区位于山东省泰安市。

## 拼接城市并计算 MD5

按附件原始顺序得到：

| 图片 | 景点 / 关键线索 | 城市名 |
| --- | --- | --- |
| 风景 1 | 七十二奇楼 | 张家界 |
| 风景 2 | 泰山“虫二”石刻 | 泰安 |
| 风景 3 | 骑楼老街 | 海口 |
| 风景 4 | 李子坝单轨穿楼 | 重庆 |
| 风景 5 | 豫园一带 | 上海 |

拼接为：

```text
张家界_泰安_海口_重庆_上海
```

使用 Python 标准库计算 MD5，字符串按 UTF-8 编码：

```python
import hashlib

cities = ["张家界", "泰安", "海口", "重庆", "上海"]
text = "_".join(cities)
result = hashlib.md5(text.encode("utf-8")).hexdigest()

print("拼接字符串：", text)
print("MD5：", result)
print("Flag：", f"HTUCTF{{{result}}}")
```

运行结果：

```text
拼接字符串： 张家界_泰安_海口_重庆_上海
MD5： 714ef967090f09ba4e1c88dbe5900f62
Flag： HTUCTF{714ef967090f09ba4e1c88dbe5900f62}
```

## 小结

这题的核心是从图片里找**有辨识度的线索**。第一张可以关注券面文字；第二张从石刻入手；第四张的轨道穿楼几乎就是城市地标；第五张则可以结合古建筑与远景高楼判断。确认五个城市后，剩下的就是严格按照题目要求拼接和计算 MD5。要特别注意不能把省名、“市”字或多余空格算进去。
