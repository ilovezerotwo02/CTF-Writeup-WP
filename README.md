# ctf附件和wp

打比赛攒下来的附件、脚本和 writeup。以前散在好几个文件夹里，找题得翻半天，就按比赛重新排了一遍丢上来。

目录格式是 `比赛 / 年份 / 题类 / 题目`，年份查不到或者记不清的就不建那一层。每个题目目录里基本都是这三样：题目给的附件（压缩包或者原文件）、解压出来的东西、自己写的 exp；写了 wp 的会有 `wp.md` 或 `*_WP.md`，少数是提交给平台时的 docx 版本。

## 目录

- [ISCC](ctf附件和wp/ISCC) 2026 擂台 + 练武，各分 web / pwn / re / misc / mobile 五个方向，题最多的一块
- [强网杯](ctf附件和wp/强网杯) 2026，pwn 占了大多数，web 和逆向各几道
- [羊城杯](ctf附件和wp/羊城杯) 2026，解出 7 道，附件和当时的脚本都在
- [御网杯](ctf附件和wp/御网杯) 数据安全、网络安全两个方向，偏审计和取证
- [HTUCTF](ctf附件和wp/HTUCTF) 学校的比赛，2025 是零散收的，2026 开始按方向分
- [金盾杯](ctf附件和wp/金盾杯) pwn / 逆向 / 密码 / misc
- [阿里CTF](ctf附件和wp/阿里CTF) 附件为主，wp 全揉在一个 md 里
- [ISCTF](ctf附件和wp/ISCTF) 2025，只有附件，没单独写 wp
- [furryctf](ctf附件和wp/furryctf) 几道 pwn，外加一份 ISCTF2025 官方 wp
- [BUUCTF](ctf附件和wp/BUUCTF) 刷题留的附件和 exp
- [启航杯](ctf附件和wp/启航杯) pwn 为主
- [软件安全对抗](ctf附件和wp/软件安全对抗) 课程的附件和 pwn 环境
- [杂题](ctf附件和wp/杂题) 来源记不清的，先堆着
- [DASCTF](ctf附件和wp/DASCTF) 2025 的 wp

每个比赛目录下还有一个 README，列了具体有哪些题、对应哪个 wp。
